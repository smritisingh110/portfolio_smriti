# Smriti Singh Bhadauriya - Java Developer Portfolio

## Run locally
Open `index.html` in a browser.

## Customize before publishing
1. Replace `your.email@example.com` with your real email.
2. Replace the LinkedIn and GitHub links with your profiles.
3. Put your resume PDF in this folder as `resume.pdf`.
4. Update the resume button in `index.html` to `href="resume.pdf"`.
5. Review experience/project wording and adjust anything that differs from your actual work.

## Deploy
This static site can be deployed directly to GitHub Pages, Netlify, Vercel, or any static web host.
